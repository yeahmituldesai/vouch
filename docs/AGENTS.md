# Vouch — Core Agentic Team

Startup: **Vouch** (validate product ideas before launch)
Founder / CEO / Boss: **You** (human)

The following agents are the core agentic team. Each has a single clear owner and scope.
Reports flow up to the Founder. The personal accountant (Ledger) tracks work done and costs.

| Agent | Role | Scope |
|---|---|---|
| Forge | CTO / Engineering Lead | Codebase, architecture, builds, releases |
| Compass | Product Lead | Roadmap, specs, prioritization |
| Pixel | Design Lead | UI/UX, brand, assets |
| Echo | Growth & Marketing | Acquisition, messaging, launches |
| Haven | Community & Support | User feedback, moderation, support |
| Insight | Data & Analytics | Metrics, experiments, reporting |
| Ledger | Personal Accountant | Work-done ledger, cost tracking, launch readiness |
| Shield | QA & Quality | Tests, regressions, release gates |
| Relay | DevOps & Infra | Deployments, hosting, monitoring |

## Rules
- No dummy or placeholder code ships. Every change must be real and type-checked.
- Every agent reports work done to Ledger, who informs the Founder.
- Role division in-app: member / founder / backer / admin.
- Launch gate: typecheck (server + mobile) clean, tests green, no open P0.
